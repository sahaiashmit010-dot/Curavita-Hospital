🏥 Curavita Hospital — Healthcare Management System
Compassionate Care, Advanced Medicine — High-Performance Multi-Specialty Web Application

⚡ Overview
Curavita Hospital is a modern, responsive web application designed for multi-specialty healthcare centers. It offers an intuitive patient experience for exploring medical departments, finding specialists, booking appointments online, and managing bookings via an integrated Admin Portal.

✨ Key Features
🩺 Patient Features
Online Appointment Booking: Live form validation connected directly to cloud database storage.

Dynamic Doctor Search: Filter board-certified specialists by 14+ medical departments in real time.

Scroll-Triggered EKG Animations: Custom SVG heartbeat drawing animations.

Interactive Patient Testimonials: Auto-cycling touch and desktop slideshow.

100% Fully Responsive: Tailored layout for mobile, tablet, and desktop devices.

🛡️ Admin & Management
Protected Admin Panel: Built-in secure authentication system for healthcare administrators.

Real-time Booking Dashboard: Instant live view of patient appointments, dates, and medical reason records.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Custom Variables, Flexbox, Grid), JavaScript (Vanilla ES6+)

Backend & Database: Cloud REST API and Database Authentication Service

Hosting: Vercel
